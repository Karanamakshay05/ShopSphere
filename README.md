# ShopSphere

A full-stack e-commerce application built using the MERN stack.

## Technologies
- React.js
- Vite
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose

## Features
- Dynamic product listing
- Product CRUD APIs
- Shopping cart
- Quantity management
- Dynamic subtotal
- LocalStorage persistence

## Setup

### Backend
cd backend
npm install

Create a .env file using .env.example.

npm run dev

### Frontend
cd frontend
npm install
npm run dev
